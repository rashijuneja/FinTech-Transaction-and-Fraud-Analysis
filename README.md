# FinTech Transaction & Fraud Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing financial transactions and identifying fraudulent transaction patterns using Data Analytics tools.

The main objective is to understand transaction behavior, analyze payment methods, compare transaction amounts across locations, and gain insights into fraudulent activities through data analysis and an interactive Power BI dashboard.

## 🎯 Project Objectives

- Analyze financial transaction data.
- Identify fraudulent and normal transactions.
- Calculate fraud percentage.
- Analyze transactions based on payment types.
- Understand location-wise transaction trends.
- Analyze monthly transaction patterns.
- Visualize key business insights through Power BI.

## 🛠️ Technologies Used

- **Python** – Data analysis and data cleaning.
- **Pandas & NumPy** – Data manipulation and preprocessing.
- **Matplotlib & Seaborn** – Data visualization.
- **MySQL** – Data storage and SQL-based analysis.
- **Power BI** – Interactive dashboard creation.
- **Jupyter Notebook** – Python development environment.

## 📂 Dataset Information

The project uses a dataset containing **5,000 financial transaction records** with the following columns:

| Column Name | Description |
|---|---|
| Transaction_ID | Unique transaction identifier |
| Customer_ID | Customer identifier |
| Merchant_ID | Merchant identifier |
| Transaction_Amount | Amount of transaction |
| Location | Transaction location |
| Payment_Type | Mode of payment |
| Transaction_Date | Date of transaction |
| Fraud_Status | 0 = Normal, 1 = Fraud |

## 🔍 Project Workflow

### 1. Data Generation & Collection
Created a transaction dataset containing 5,000 records for analysis.

### 2. Data Cleaning Using Python
- Checked missing values.
- Removed duplicate records.
- Converted transaction dates into datetime format.
- Explored dataset using Pandas.

### 3. SQL Analysis Using MySQL
Performed SQL queries to analyze:
- Total number of transactions.
- Payment-type-wise transactions.
- Location-wise transaction analysis.
- Monthly transaction trends.
- Fraud and normal transaction counts.
- Top customers and merchants.
- Average, maximum, and minimum transaction amounts.

### 4. Power BI Dashboard
Created an interactive dashboard with:
- Total Transactions
- Fraud Transactions
- Fraud Percentage
- Total Transaction Amount
- Payment Type Analysis
- Location-wise Transaction Analysis
- Monthly Transaction Trend
- Fraud vs Normal Transaction Analysis

## 📊 Key Project Insights

Based on the analyzed dataset:

- **Total Transactions:** 5,000
- **Normal Transactions:** 4,720
- **Fraud Transactions:** 280
- **Fraud Percentage:** 5.60%
- **Normal Transaction Percentage:** 94.40%

The dashboard helps understand transaction distribution, payment preferences, location-wise activity, and fraudulent transaction patterns.
